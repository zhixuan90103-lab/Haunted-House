## 2. 第 1 轮结论 · 外部标杆

### 2.1 ThinkFun Laser Maze（主参照 · 说明书核对）

**组件（官方 Token Guide）：**

| Token | 作用 | 与我方 |
|-------|------|--------|
| Laser | 源；按钮开光 | 手电（放置后自动 lit，无实体激光） |
| Target/Mirror | 可作目标、镜、或两者；**仅透明红面算目标** | 鬼=纯目标；镜=纯折；**无「目标兼镜」复合件** |
| Beam Splitter | 一路 90° 反射 + 一路直穿 | `beam_splitter`（后期批次，非本讨论池） |
| Double-Mirror | **双面**皆 90° 反 | 我方基础镜**单面**；不可按双面出题 |
| Checkpoint | 光束**必须经过**该格 token | 无直接件 → 用「空格必经 + 墙逼路」或以后专用件 |
| Cell Blocker | **占格禁放其它 token**；**不挡激光** | 近：墙挡光且占格；鬼占格**不挡光**（更像 blocker 的「占位不挡光」） |

**挑战卡结构（精妙核心）：**

| 卡面信息 | 含义 | 本项目映射 |
|----------|------|------------|
| 网格上的符号 | **固定位置**必须摆上 | `walls` + `lockedProps` + 固定鬼 |
| 符号**有轮廓朝向** | 位置+朝向都钉死 | locked + 给定 facing |
| 符号含 **?** | 位置钉死，**朝向自解** | locked 可转 / 或「钉位自由旋」 |
| **ADD TO GRID** | 本关**必须用上**的自由件清单 | `tray[]`；**必须用尽**（见胜负） |
| **# OF TARGETS** | 要点亮的目标数 | 鬼数（全员显示）或「至少 N」——我方胜负是**全员** |

**胜负（说明书原文要点）：**

1. 激活的 **Target 数量 = 卡面要求**  
2. 光束须碰到卡上**所有应在盘上的 token** 至少一次（**Cell Blocker 除外**）  

→ 精妙点：**不是只打目标，还要「用完」所有摆上的件**（防闲置镜）。  
→ 我方若 tray 有镜，应追求：**标准解用尽托盘必要件**；可选规则「闲置件算失败」作专家变体（PRODUCT 未写，出题纪律先执行）。

**难度分档：** Beginner → Intermediate → Advanced → Expert（约 60 卡）。

**布置规则（精妙相关）：**

- 卡图上的件：**不得挪格**；有 `?` 可旋不可移  
- ADD TO GRID 的件：**全部用上**，其余盒内件本关不用  
- 解完翻卡对答案（我方 = `reference` 字段）

**挑战开发署名（可溯源）：** Wei-Hwa Huang, Tyler Somer, Luke Hooper, Tanya Thompson 等。

### 2.2 Laser Maze 可借鉴手法库

| ID | 手法 | Laser 表现 | 我方做法 |
|----|------|------------|----------|
| L1 | **预置降维** | 大半件钉在卡上 | 墙 + locked 灯/镜 + 固定鬼 |
| L2 | **朝向谜** | `?` 只考旋转 | 钉位镜，只给点旋 |
| L3 | **资源紧** | ADD 列表刚好够 | tray 件数 = 标准解件数 |

### 2.3 路径规划 / 覆盖同构（旁参照）

光路题 ≈ **在障碍图上构造有向路径 + 可选覆盖算子**。

| 规划概念 | 谜题用法 | 5×5 出题动作 |
|----------|----------|--------------|
| **割边/割点** | 去掉某通道则不可达 | 墙切断源区与鬼区 |
| **必经格** | 所有解共享的格子 | 窄走廊 + 唯一拐点空档 |
| **区域分割** | 多连通分量 | 中心墙分左右，逼跨区折 |
| **覆盖半径** | 一点服务多目标 | 漫光 8 邻 = 半径 1 的 Chebyshev 覆盖 |
| **终止汇点** | 路径终点有语义 | 漫光 = 汇点且终止，其后无直线 |
| **容量/资源** | 边权或件数上限 | tray 镜≤2、灯≤1 |
| **CSP 推理** | 「若灯在左则镜必须…」 | 诱错位 + 唯一合法朝向 |

**路径类手游常见节奏（可映射教学序）：**

1. 空图直达  
2. 加障碍 → 必折  
3. 只转不挪 → 再给挪  
4. 多目标 / 特殊终点  

### 2.4 禁止错误借鉴（核实）

| 外部 | 我方 | 出题禁令 |
|------|------|----------|
| Double-Mirror 双面 | 单面镜，反面墙 | 禁止按双面出「两面都能折」 |
| Target 兼镜 | 鬼≠镜 | 禁止「鬼当反射板」 |
| Cell Blocker 不挡光 | 墙挡光；鬼不挡光 | 墙与鬼职责分开写清 |
| 光须碰所有 token | PRODUCT 未写 | 纪律上「必要件用尽」；勿当未写的玩家规则强加 UI |
| 连续角激光 | 四向格点 | 禁止斜射解 |
| 隐藏目标 | 有 Hidden/扫光 | **精妙主考布局**；探查另关或弱化 |
| 即时激光反馈 | 放置后 lit | 可接受；扫光是附加信息 |

## 3. 第 2 轮结论 · 映射本项目

### 3.1 道具 = 规划原语

| 道具 | 原语 | 精妙用法 | 庸俗用法 |
|------|------|----------|----------|
| 手电 | **源** | 源落区被墙/鬼限制；半边放错全灭 | 多灯并集替代一切折 |
| 镜子 | **有向折点** | 必经拐点、`?` 朝向、反面诱错 | 直线已通仍摆镜 |
| 漫光 | **覆盖汇点** | 团目标；激活格不可直达 | 空图直射激活 |

### 3.2 出题原子（实例化）

| ID | 原子 | 玩家推理 | 制造 | Laser 对应 |
|----|------|----------|------|------------|
| A1 | 直射 | 无挡则直达 | 空通道 | Beginner 直打 target |
| A2 | 挡直逼折 | 直线废了 | 墙切断 | 障碍逼折 |
| A3 | 单折 90° | 这里必须拐 | 1 镜 + 唯一拐点 | Mirror + 钉位 |
| A4 | 双折跨区 | 一区送不到另一区 | 2 镜 + 分割墙 | 多折 Expert |
| A5 | 反面无效 | 朝向反了全黑 | 单面表 | 非 Double-Mirror |
| A6 | 漫光覆盖 | 一团要一片 | L/团鬼 + 邻格激活 | 近似多 target 区域 |
| A7 | 漫光终止 | 漫后无直线 | 远处假目标在漫后 | 路径终点语义 |
| A8 | 占格禁手 | 好格有鬼 | 鬼占优灯/镜位 | Cell Blocker 变体 |
| A9 | 资源紧 | 少一件无解 | tray=标准解 | ADD TO GRID 用尽 |
| A10 | 预置约束 | 钉死位/向 | locked / 墙 | 卡面 outline |
| A11 | 必经走廊 | 光必须走这格 | 窄道 | Checkpoint 近似 |

**一关：1 主原子 + 至多 1 辅原子。**

### 3.3 题型原型（托盘 ≤3 件口径）

| 原型 | 托盘 | 主+辅 | 精妙要点 |
|------|------|-------|----------|
| **P1 折入** | 灯1 镜1 | A2+A3 | 唯一拐点；Q 朝向可选 |
| **P2 双折跨区** | 灯1 镜2 | A4+A9 | 两区各≥1 鬼；缺一镜无解 |
| **P3 送货漫光** | 灯1 镜1 漫1 | A3+A6 | 激活格不可直射；镜负责送 |
| **P4 终止陷阱** | 灯1 镜1 漫1 | A6+A7 | 漫后假直线诱惑 |
| **P5 钉死镜** | 灯1 镜1 + locked 镜 | A10+A3 | 自由件只补一条腿 |
| **P6 鬼占优位** | 灯1 镜1 | A8+A2 | 最优灯位是鬼格 |

## 4. 第 3 轮 · 精妙标准与规程

### 4.1 精妙度检查表（出题必过）

| # | 检查 | 来源 |
|---|------|------|
| Q1 | 一句话只含 **一个主原子** | 防堆砌 |
| Q2 | 去掉任一**必要件** → 无解 | Laser「用尽」纪律 |
| Q3 | 无「不摆镜/不摆漫」傻解 | 封直射 |
| Q4 | 标准解可 **3 句口播** | 防过绕 |
| Q5 | 至少 **一处诱错**（反面/假通道/假激活格） | Laser Expert 味 |
| Q6 | 盲测偏推理而非全盘穷举 | 预置降维 L1 |
| Q7 | 鬼占格是否贡献精妙（优位被占） | A8 / L7 |
| Q8 | 光路与 OPTICS 表一致（单面、漫终止、穿鬼） | 禁双面/斜射 |

### 4.2 倒推规程（Laser 卡 + 终态）

```
① 选原型 P* + 主原子
② 画终态 lit ⊇ 全部鬼格；标标准解 灯/镜/漫 位姿
③ 手算：穿鬼、mirrorOut、漫 8 邻、终止
④ 删自由度：墙封傻解、tray 收到恰好、locked 钉死
⑤ 证明 Q2：逐件移除仍可解? → 必须否
⑥ 题面只留 墙/鬼/locked/tray
⑦ 写诱错与 reference
⑧ 盲测 → 改
```

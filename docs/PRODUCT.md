## 1. 产品定位

### 1.1 一句话

**固定房间谜题：用光学道具铺光路，让所有鬼同时「完全显示」，再拍照合影——拍完才算抓到并过关。**

### 1.2 玩家在解决什么

```
目标：场上所有鬼（分散、固定位置）
手段：手电（光源）+ 镜 / 漫射等道具规划光路
约束：场景家具/墙；一格一物；托盘道具有限
胜利：全员同时被光照成「完全显示」→ 拍照
```

单光源往往照不全分散的鬼 → **必须布局**（镜转折、漫射扩面、多灯并集等）。

### 1.3 设计取舍（讨论结论）

| 要 | 不要 |
|----|------|
| 轻策略：布局、朝向、光路 | 硬核唯一解压迫（可多组合） |
| 一点点推理 + 空间 | 纯过场体验 |
| 固定谜题可复现 | 随机鬼位刷本 |
| 工具特性差异 | 多把完全同质盖子 |
| 托盘拖放（类 BB 手感） | BB 消行玩法 |
| 全员示众 + 拍照 | 驱逐清空式胜利 |

### 1.4 品类邻近与差异

- 邻近：激光反射 / 布光谜题。  
- 差异：捉鬼状态机（隐藏→显示→透明）、探查拖光、**全员显示后强制进拍照**、房间题材包装。

## 2. 一局流程

```
进入关卡（固定：鬼位、场景、托盘道具）
  → 从托盘直接拖道具到盘（类 BB）
  → 拖动光源也会发光：改变鬼的显示状态
  → 摆放/旋转镜、漫射等，规划光路
  → 多光源照亮取并集
  → 所有鬼同时「完全显示」
  → 锁盘 + 拍照 UI（可「返回」改布局）
  → 拍照成功 → 抓到 → 过关
```

重开：整关回到最开始（见 §8）。

## 3. 总纲八条

| # | 规则 |
|---|------|
| 1 | 光有朝向，**直线**走；遇物按特性变（格点光学直觉）。 |
| 2 | 手电数量**按关**；朝向**逻辑四向**（点旋四档）。 |
| 3 | 透明=知位置；完全显示=当前在灯下；**抓到=全员显示后拍照**。 |
| 4 | 无强制探查/布光阶段门；道具可反复拿起。 |
| 5 | 鬼 **1 格**、**不挡光**；所在格被照亮则可完全显示。 |
| 6 | **道具**玩家摆；**场景**关卡写死。 |
| 7 | **一格一物**；光不占格。 |
| 8 | **固定谜题**，鬼位不随机。 |

## 4. 盘面与占格

| 项 | 规则 |
|----|------|
| 默认盘 | **5×5**（关卡参数可调） |
| 一格一物 | 道具、场景、鬼站位互斥，**不可重叠** |
| 光 | 不占格，只标记「亮格」集合 |
| 鬼格 | 占实体；**不可再放道具**；光可穿过并照亮 |

---

## 5. 光

| 项 | 规则 |
|----|------|
| 起点 | 手电等光源的朝向 |
| 路径 | 直线向前，直到出界或撞挡/改光物 |
| 手电自身格 | **不亮** |
| 路径格 | 经过则亮 |
| 多光源 | **并集**（任一路照到即亮） |
| 挡光场景 | 光停；**挡光格不亮** |
| 手电/镜/漫射所占格 | **不计入照亮** |

---

## 6. 鬼

### 6.1 属性

| 项 | 规则 |
|----|------|
| 数量/位置 | 按关固定 |
| 占地 | 1 格 |
| 挡光 | **否** |

### 6.2 状态机

```
完全隐藏 ──(当前被光照到)──► 完全显示
     ▲                            │
     │                     (灯移开且曾被照到)
     │                            ▼
  (仅重开重置)                  透明 ◄──(再次被照到)── 完全显示
```

| 状态 | 含义 | 抓到？ |
|------|------|--------|
| 完全隐藏 | 初始；从未被照到 | 否 |
| 完全显示 | **此刻**在灯光下 | 否（须拍照） |
| 透明 | 曾照到，灯已离开；知位置 | 否 |
| 抓到 | 全员完全显示后**拍照成功** | 是 |

说明：

- 拖动光源时**也发光**，会驱动隐藏→显示、显示→透明。  
- 「算在抓鬼」≠「算抓到」；过关只认拍照。

---

## 7. 胜利与相机

```
触发：所有鬼同时 = 完全显示
  → 禁止盘面操作
  → 进入拍照界面
      · 拍照 → 全员抓到 → 过关
      · 返回 → 解锁盘面，可改布局（少用）
```

---

## 8. 重开

```
重开本关 = 最初状态
· 鬼全部完全隐藏
· 道具全部回托盘
· 退出相机
· 清空盘上玩家摆放
```

## 9. 道具

### 9.1 总表（确定 vs 备选）

#### 确定（v1 规则承诺，优先实装）

| id | 名称 | 角色一句话 |
|----|------|------------|
| `light` | **光源**（手电） | 探测 + 沿朝向发射直线光 |
| `mirror` | **镜子**（基础镜） | 正面 90° 反射；反面当墙 |
| `beam_splitter` | **半透半反镜** | 一路 90° 反射 + 一路沿原向透射 |
| `diffuser` | **漫射灯** | 被光束打中后，周围 8 格亮，原光终止 |

#### 备选（未承诺实装，出题/扩展时选用）

| id | 名称 | 角色一句话 | 备注 |
|----|------|------------|------|
| `light_short` | 短射程光源 | 只照前方有限格 | 源类变体 |
| `light_dual` | 双头灯 | 两相反方向同时射 | 源类 |
| `light_corner` | 角灯 | 两垂直方向同时射 | 源类 |
| `mirror_double` | 双面镜 | 两面皆可反射 | 镜类 |
| `splitter_prism` | 棱镜分束 | 其它分束几何 | 与半透半反重叠时慎加 |
| `mirror_u` | 直角回转槽 | 强制 U 形折回 | |
| `portal_pair` | 传送门对 | 光进 A 从 B 出 | 需成对规则 |
| `pipe` | 光纤/弯管 | 强制沿管走一格再出 | |
| `cross_lamp` | 十字灯 | 中弹后十字方向亮 | 扩面类 |
| `bar_lamp` | 条灯 | 中弹后整行或整列亮 | 扩面类 |
| `flash_once` | 一次性爆闪 | 3×3 亮后失效 | |
| `blocker` | 可搬挡板 | 玩家放置的挡光 | |
| `one_way_glass` | 单向玻璃 | 只许单方向穿过 | |
| `filter` | 滤光片 | 色光/条件光（若以后有通道） | 依赖扩展规则 |
| `shutter` | 快门/联动门 | 被照后改邻格通断 | 偏时序，慎 |
| `light_sink` | 吸光件 | 吃光不反不透 | |
| `relay_source` | 二次源 | 被照亮后再射出 | 难控，慎 |
| `bait` | 诱饵/香炉 | 主要改探查反馈，少改光 | 弱光学 |
| `pass_through_base` | 通光底座 | 占格但光可穿 | 占格特例 |

**场景固定件**（一般不进托盘，属关卡布局，备选思路）：固定镜、固定挡板、染色窗、透光缝、不可放道具的神坛格等。

---

### 9.2 通用操作（确定道具共通）

| 项 | 规则 |
|----|------|
| 位置 | 开局在**盘外托盘** |
| 取出 | **直接从托盘拖到盘**（类 BB） |
| 收回 | 拿起可放回托盘 |
| 操作 | 全道具统一：**拖放 + 点击旋转** |
| 旋转 | 有朝向则改规则档位；无规则朝向也旋转（**要有反馈**） |
| 占格 | 一格一物；道具格**不计入照亮**（与 §5 一致） |

---

### 9.3 光源（确定 · `light`）

| 项 | 规则 |
|----|------|
| 角色 | 探测 + 发射光源 |
| 数量 | 按关配置 |
| 朝向 | **逻辑仅四向**（N/E/S/W）；点击旋转切换四档（表现勿做未定义斜向光） |
| 发光 | 前方直线至边界/障碍；**自身格不亮** |
| 拖动 | 拖动中也发光，影响鬼状态 |
| 多源 | 照亮取**并集** |

---

### 9.4 镜子（确定 · `mirror`）

| 项 | 规则 |
|----|------|
| 类型 | **单面直角转向镜**（非物理双向 45° 斜镜；算法见 OPTICS_SPEC） |
| 反射 | **90°**；每档仅 **2 个入射方向**有效 |
| 朝向 | **4 档**；拖放 + 点旋 |
| 正面 | 表内入射 → 反射后继续亮路径 |
| 反面 | **当墙**（光停、镜格不亮；可再调） |
| 镜格 | 不亮 |

---

### 9.5 半透半反镜（确定 · `beam_splitter`）

| 项 | 规则 |
|----|------|
| 别名 | 分束镜、半透半反 |
| 朝向 | **4 档**（与基础镜同一套操作） |
| 正面入射 | **同时**产生两路光：① 按基础镜规则 **90° 反射**；② **沿原方向透射**继续走 |
| 两路 | 各自继续直线，直到出界或再撞其它物；照亮取并集 |
| 反面 | 暂与基础镜一致：**当墙**（可再调） |
| 自身格 | 不亮 |
| 出题价值 | 一源喂两路，服务分散多鬼 |

---

### 9.6 漫射灯（确定 · `diffuser`）

| 项 | 规则 |
|----|------|
| 激活 | 光束打到**其所在格** |
| 效果 | 周围 **8 格**被照亮 |
| 原光束 | **终止**（不穿出、不沿原方向继续） |
| 自身格 | 不亮 |
| 旋转 | 点旋有反馈，**不改变散射规则** |

---

### 9.7 场景（非托盘道具）

- 墙、家具、固定挡光/引光等，关卡写死。  
- 占格；挡光默认：停、格不亮。  
- 不进托盘（除非将来单独做可搬场景件）。

---

### 9.8 备选启用原则

```
① 一句话能说清，符合格点光学直觉
② 优先只改「方向 / 范围 / 通断」之一
③ 与四个确定件功能高度重叠则不加
④ 小盘托盘同时出现的种类宜 ≤ 3～4
⑤ 启用前写入题卡 teaches/requires，并补 LEVEL_DESIGN 原子标签
```
